# Docs package

Public case-study assets for the GitHub repository.

| Path | Purpose |
| --- | --- |
| [CASE_STUDY.md](CASE_STUDY.md) | Product write-up (problem, solution, architecture) |
| [screenshots/](screenshots/) | Live UI captures embedded in the root README |
| [fixtures/](fixtures/) | Generated sample images used by the capture script |

Regenerate screenshots (dev server must be running):

```bash
npm run capture:case-study
```
